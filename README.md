# 📐 Gauss-Jordan Elimination Solver

Консольное приложение на C++ для решения систем линейных алгебраических уравнений (СЛАУ) и нахождения обратных матриц методом Жордана-Гаусса.

## 📌 Описание проекта
Программа реализует численный алгоритм полного исключения неизвестных (метод Жордана-Гаусса). Алгоритм приводит расширенную матрицу системы к единичному виду с помощью элементарных преобразований строк.

## 🛠️ Стек технологий
* **Язык программирования:** C++ (работа с двумерными массивами/матрицами, циклы, условные операторы)
* **Математический аппарат:** Линейная алгебра, матричные вычисления, численные методы

## 🚀 Основные возможности
* Пошаговый вывод промежуточных матричных преобразований.
* Автоматический выбор ведущего (разрешающего) элемента.
* Обработка особых случаев: проверка системы на совместность и выявление линейно зависимых строк.
